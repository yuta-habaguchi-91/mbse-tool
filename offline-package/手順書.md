# 業務関係整理ツール オフラインインストール手順書

## 概要

本ツールは Python (FastAPI) + React で動作する業務関係整理ツールです。  
ブラウザ上でブロック（業務）とコネクタ（関係）を配置してダイアグラムを作成できます。  
インターネット接続なしでインストール・動作可能です。

---

## フォルダ構成

```
offline-package/
├── 手順書.md          ← このファイル
├── setup.bat          ← 初回セットアップ用スクリプト
├── start.bat          ← ツール起動スクリプト
├── 01_packages/       ← Python パッケージ (wheel ファイル 20個)
└── app/
    ├── backend/       ← Python/FastAPI アプリケーション
    │   ├── data/
    │   │   └── graph.json   ← 図データの保存先
    │   └── ...
    └── frontend/
        └── dist/      ← ビルド済み React アプリ (静的ファイル)
```

## インストール手順

### ステップ 1: Python 3.13 のインストール

Python がまだインストールされていない場合は以下の手順で行います。

1. Python インストーラーを用意する  
   → **オンライン PC** で `https://www.python.org/downloads/` から  
   `python-3.13.x-amd64.exe` をダウンロードし、USBメモリ等で転送

2. インストール実行  
   - インストーラーを起動  
   - **「Add Python to PATH」にチェックを入れる**（重要）  
   - 「Install Now」でインストール

3. インストール確認  
   コマンドプロンプトを開いて以下を入力:
   ```
   python --version
   ```
   `Python 3.13.x` と表示されれば OK

### ステップ 2: uv のインストール

uv がまだインストールされていない場合:

1. コマンドプロンプトを開いて以下を実行:
   ```
   python -m pip install uv
   ```

   > インターネットに接続できない場合は、オンライン PC で uv の wheel ファイルを
   > ダウンロードしてから pip でインストールしてください。
   > ```
   > # オンライン PC で実行
   > pip download uv -d uv_wheel\
   > ```
   > 転送後にオフライン PC で:
   > ```
   > pip install --no-index --find-links uv_wheel\ uv
   > ```

2. インストール確認:
   ```
   uv --version
   ```
   バージョンが表示されれば OK

### ステップ 3: フォルダの配置

`offline-package` フォルダごと、任意の場所に配置します。  
**パスに日本語や空白が含まれないフォルダを推奨します。**

例:
```
C:\Tools\offline-package\
D:\Apps\offline-package\
```

### ステップ 4: 初回セットアップ（1回のみ実行）

`offline-package` フォルダ内の **`setup.bat`** をダブルクリックします。

```
[1/2] Python 仮想環境を作成中...
[2/2] パッケージをインストール中 (インターネット不要)...
============================================
 セットアップ完了！
 start.bat でツールを起動してください。
============================================
```

上記のように表示されれば完了です。

## 起動手順（毎回）

`offline-package` フォルダ内の **`start.bat`** をダブルクリックします。

```
============================================
 業務関係整理ツール 起動中...

 ブラウザで以下を開いてください:
   http://localhost:8000
...
============================================
```

ブラウザのアドレスバーに `http://localhost:8000` を入力してアクセスします。

---

## 終了方法

ツールを終了するには、起動中のコマンドプロンプト画面で **Ctrl+C** を押します。

---

## データの保存場所

図データは以下のファイルに自動保存されます（「保存」ボタン押下時）:

```
offline-package\app\backend\data\graph.json
```

バックアップする場合は `graph.json` をコピーしてください。  
別 PC に移行する場合も、このファイルをコピーすれば図が引き継がれます。

## トラブルシューティング

### `uv: command not found` または `uv は認識されていません`

→ uv がインストールされていないか、PATH に含まれていません。  
「ステップ 2」を再実施してください。  
または、コマンドプロンプトを **管理者として実行** して再試行してください。

### `Python 3.13 が見つかりません`

→ `setup.bat` 内の Python バージョン指定を確認します。  
インストール済みの Python バージョンを `python --version` で確認し、  
`setup.bat` の `--python 3.13` の部分をインストール済みバージョンに合わせてください。

### ブラウザで `接続できません` と表示される

→ `start.bat` のコマンドプロンプトが起動していることを確認してください。  
起動後、数秒待ってからブラウザを更新してください。

### ポート 8000 が使用中のエラー

→ 別のアプリが 8000番ポートを使用しています。  
`start.bat` をテキストエディタで開き、最終行の `--port 8000` を `--port 8001` 等に変更し、  
ブラウザのアクセス先も `http://localhost:8001` に変更してください。

## 主な機能

| 操作 | 説明 |
|------|------|
| ＋ ブロック追加 | 新しい業務ブロックを追加 |
| ブロックをドラッグ | 位置を移動 |
| ハンドル（◯）をドラッグ | コネクタ（矢印）を引く |
| Ctrl + ブロッククリック | 1つ目→2つ目の順でクリックして自動接続 |
| ブロック選択後に再クリック | 名前をインライン編集 |
| ブロックをダブルクリック | プロパティ編集（資料番号・担当者・改訂履歴） |
| 接続整列ボタン | 全矢印を最近接ハンドルに再接続 |
| 保存ボタン | graph.json に保存 |
| 読込ボタン | graph.json から読み込み |
| Ctrl+Z | 元に戻す |
| Delete | 選択中のブロック/矢印を削除 |
| ビュータブ ＋ | 同じデータで別レイアウトのビューを追加 |
